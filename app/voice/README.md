# Voice (reservado)

## Papel

Transformar **texto já gerado** em áudio (TTS).

## Não faz

- Personalidade
- Emoção (só pode *interpretar* tom já decidido)
- Memória / Reasoning
- Discord (Bridge entrega o áudio no canal)

## Fluxo futuro

```text
Language → texto
    ↓
Voice → áudio
    ↓
Bridge/Discord → envia
```

SUTAC e hesitações pertencem à **Language** (ou marcações no texto), não ao codec de voz.
