# Identity — identidade narrativa

## O que é

Dados **estáveis** de quem a Yelena é:

- nome, natureza (IA), valores
- relação com Kauã (criador/admin, não obediência cega)
- PH (Douglas) e ciúmes possíveis
- regras de fala (pt-BR natural, SUTAC depois)

## O que não é

- Personality → traços numéricos
- Emotion → estado do momento
- Memory → experiências acumuladas
- Language → geração do texto
